# V28 — Che dữ liệu tại ranh giới báo lỗi

Phạm vi: mọi chuỗi trong JSON báo cáo (kể cả session, env, log DEBUG API 30, vệt), file phiên/vệt và nội dung clipboard. Đường lưu, gửi tay, gửi tự động dùng chung bộ che; báo cáo cũ được che khi đọc. Giữ số và boolean.

Đạt khi: các chuỗi giả Bearer/Basic, khóa RA `y=`, query `key=`/`token=`, email, URI `content://`/`file://`, đường dẫn có dấu cách/tiếng Việt không lọt vào JSON trên đĩa, HTTP hoặc clipboard.

Kiểm: `DiagnosticsPrivacyTest` phủ lưu, gửi tay/tự động bằng interceptor, clipboard, file cũ, vệt/phiên; `DiagnosticsTest` kiểm Bearer. `git diff --check` đạt. `./gradlew testDebugUnitTest` chưa chạy tới test: tải Gradle qua proxy thành công nhưng cấu hình dừng vì thiếu Android SDK (`SDK location not found`). Chờ CI Build.

Giả định: ẩn toàn bộ đường dẫn riêng, gồm tên file (PM phản đối thì đổi). Đường dẫn mơ hồ có dấu cách được che tới cuối dòng/chuỗi hoặc dấu nháy; có thể mất thêm phần thông báo để tránh lộ tên riêng. Không sửa định dạng báo cáo hay endpoint.
