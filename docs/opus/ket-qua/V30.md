# V30 — Release phải ký thật và checkout đúng tag

Phạm vi: workflow Release. Checkout `refs/tags/<tag>` đã tồn tại; chặn tag không hợp lệ/sai HEAD và thiếu bất kỳ cấu hình ký nào trước build. Bỏ nhánh ký debug khi chạy tay. APK phải qua apksigner, chặn chứng chỉ Android Debug trước upload; ghi SHA-256 APK + mapping vào ghi chú và file kiểm tổng.

Đạt khi: cửa chặn thực tế trong YAML dừng với input giả thiếu cấu hình ký cho cả dispatch/push; tag sai và chứng chỉ debug bị chặn; ghi chú chứa đúng hai hash.

Kiểm: `python3 scripts/test-release-guards.py`: 6/6 test đạt (bao gồm 8 tổ hợp thiếu trường/event). Chỉ chạy cửa chặn với Git/tệp/chứng chỉ giả ở thư mục tạm, không gọi ký, build release hay publish. Build chạy cùng bài kiểm. `git diff --check` đạt. `./gradlew testDebugUnitTest` dừng vì thiếu Android SDK; chờ CI.

[CHƯA KIỂM] ký APK thật/Release chạy thật: Sol không có nhiệm vụ hoặc quyền thao tác khóa/phát hành. Dùng cửa chặn inline để khi checkout tag cũ vẫn có kiểm tra, không phụ thuộc script mới có trong tag. Giữ mặc định prerelease của V31.
