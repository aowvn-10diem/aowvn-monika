- Nguyên nhân (chắc): mkxp-z Android chỉ có MiniFFI (dlopen); DLL Windows không tồn tại. Script game gọi `Win32API.new('user32', …)`.

Không sửa script game.
- Kiểm: `ruby scripts/test-rgss-compat.rb` (8 kiểm, qua cục bộ) + `MkxpConfigWriterTest.preloadGopVaGiuMucCuaGame`. **Đã kiểm trên máy ảo** (Emulator Test API 34, gói rgss-7 nháp, run 37187289205 @ `7d5c632`): game XP thử tự sinh gọi `Win32API.new('user32','GetAsyncKeyState',…).call(1)` ngay đầu script → ghi `ok 0`, dòng `WIN32 rgss Win32API(user32): ok 0` trong log CI; phím Enter vẫn đạt (`KEY_OK`). Nghĩa là mkxp-z **thực sự nạp** shim qua `preloadScript`. **[CHƯA KIỂM]** với game VX Ace thật (Debug Extension:178): cần Sol chạy lại ca Ace trên APK của nhánh.
