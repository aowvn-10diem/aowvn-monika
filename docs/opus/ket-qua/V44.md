## 1) VX Ace — `Debug Extension:178`: RuntimeError, `Failed loading user32: dlopen failed`
- Nguyên nhân (chắc): mkxp-z Android chỉ có MiniFFI (dlopen); DLL Windows không tồn tại. Script game gọi `Win32API.new('user32', …)`.
- Sửa (ở app, **không cần dựng lại gói rgss**): `assets/rgss/monika-win32api.rb` định nghĩa lại `Win32API` — DLL Windows (user32, kernel32, gdi32, shell32, winmm, advapi32, …) trả hàm giả an toàn (phím/chuột = 0, FindWindow = 1, GetWindowRect điền cỡ `Graphics`, GetCursorPos điền (0,0), MessageBox = IDOK, GetSystemMetrics 640×480…); DLL khác thử MiniFFI gốc. `RgssGameActivity.start` chép script ra `filesDir/rgss-compat/` và `MkxpConfigWriter` thêm đường dẫn vào khóa `preloadScript` của `mkxp.json` (gộp, giữ mục của game). Không sửa script game.
- Kiểm: `ruby scripts/test-rgss-compat.rb` (8 kiểm, qua cục bộ) + `MkxpConfigWriterTest.preloadGopVaGiuMucCuaGame`. **[CHƯA KIỂM]** trên máy ảo với game thật: cần Sol chạy lại ca Ace trên APK của nhánh `sonnet/V44-rgss-compat`.
