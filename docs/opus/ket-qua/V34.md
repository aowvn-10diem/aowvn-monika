# V34 — Kiểm config trước khi áp dụng

Phạm vi: config từ xa và cache. Kiểm dữ liệu JSON gốc trước parse/coerce: URL có giá trị phải HTTPS hợp lệ (kể cả endpoint, script, link cộng đồng, danh sách adblock), hash có khai báo phải đúng 64 hex (gồm từng ABI), runner thuộc libretro/web/apk/external/j2me. Từ chối version thấp hơn bản đang dùng; cache khởi động phải >= bản đóng gói.

Đạt khi: config hỏng hoặc lùi version không thay StateFlow/cache tốt; có lỗi app:config trong Diagnostics. Ghi cache bằng AtomicFile (file tạm + đổi tên, phục hồi bản dự phòng), khóa refresh để hai lượt tải không vượt nhau.

Kiểm: thêm ConfigRepositoryValidationTest cho nâng rồi lùi version, URL/hash/runner/sai kiểu/JSON lỗi, cache hỏng, lỗi ghi file tạm, restart đọc bản tốt, HTTPS template và hash hoa. `./gradlew testDebugUnitTest` dừng do thiếu Android SDK; chờ CI Build. `git diff --check` đạt.

Phụ thuộc V28 (#23). Giả định: URL rỗng/trường không khai báo vẫn được phép theo config cũ; hash có khai báo (kể cả rỗng) phải 64 hex (PM phản đối thì đổi). Không đổi schema, endpoint hay config chuẩn.
