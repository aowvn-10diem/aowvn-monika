## Kết quả
- `renpy-8.5.3-rapt.zip` (68.554.524 byte, SHA-256 `8a12be34…059b00e6`) **không chứa** `private/` hay thư viện Python: chỉ có Java (`org.renpy.android.*`, `org.jnius.*`, `org.libsdl.app.*`), `jniLibs/<abi>/librenpython.so` (arm64 35.975.712 / armv7 31.421.876 / x86_64 38.911.592 byte, chưa nén), `blocklist.txt`, `keeplist.txt`, công cụ Python dựng APK.
- `private/` được RAPT tạo từ **thư mục phân phối của SDK** (`rapt/buildlib/rapt/build.py: split_renpy`). Thay vì dựng APK (cần Android SDK), chạy `launcher distribute the_question --package android --no-archive --packagedest …` của SDK 8.5.3 (SHA-256 `ff57648f…b505e`) **chạy được trên CI** và ra thư mục:

| Mục | Kích thước (chưa nén) | Vai trò |

| `the_question.py` | 8.944 B | thành `private/main.py` (đổi tên) |

- `blocklist.txt` của RAPT loại: `/include`, `**~`, `**.bak`, `**.rpy`, `**.swp`, `**.pyo`, `**.pyx`, `**.pxd`, `**/.**` (giữ trong script ráp gói).

## Dung lượng gói `renpy8-arm64` (ước tính, chưa đóng gói)
`librenpython.so` 36 MB + `renpy/` 8,4 MB + `lib/` 17 MB ≈ 61 MB chưa nén; nén zip ≈ 20–25 MB **[ƯỚC TÍNH]** → lớn hơn 15 MB → app hỏi "Tải luôn bằng 4G / Đợi Wi-Fi" (đúng luật). Số thật đo ở V04.

## Hỏng trước khi ra kết quả (4 lần, 4 nguyên nhân khác nhau — đều của CI Monika, không phải của Ren'Py)
1. `android.py` (python3 hệ thống) không có module `renpy`; 2. thiếu phần mở rộng `renpy.pygame` (cần Python riêng của SDK); 3. `android.py` chèn `buildlib` theo đường dẫn tương đối; 4. Python riêng của SDK không đọc `PYTHONPATH`. → bỏ hẳn đường dựng APK, dùng `distribute --no-archive` (không cần `android.py`/Android SDK).
