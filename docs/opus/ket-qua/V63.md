## Thay đổi

1. Bỏ comment, PR edited/closed và Build-completed; giữ push main, PR opened/synchronize/reopened/ready_for_review, cron và manual vốn có. PR chỉ preview, job token ghi chỉ chạy non-PR với checkout main. Một concurrency group, cancel lượt cũ.
2. HTTPError chỉ giữ status, phân loại message cố định (primary/secondary rate-limit, permission, unknown) và header numeric `X-RateLimit-Remaining`, `X-RateLimit-Reset`, `Retry-After`. Không ghi response body, Authorization, token, header khác hay URL request. Lần GET thành công đầu cũng ghi quota numeric, để lần sau có dữ liệu thật phân biệt quota/quyền.
3. 403/429 retry tối đa 3 attempt, chờ 5/15 giây hoặc hint server trong giới hạn 30 giây mỗi lần. Reset/Retry-After >30s thì nhường cho trigger sau, không retry sớm trái hint server. 404/error khác không retry; lỗi mạng/JSON khi mutation không retry mù.
4. GET cache theo URL đã kiểm repo; tối đa 160 request mỗi lượt, kể cả retry. Dùng lại metadata commit từ inventory main cho nhánh trùng SHA; ghi tổng request và nhóm cố định, không URL/query. Quá ngân sách hoặc transport fail → warning, không đăng digest một phần.
5. Job phụ trợ có cảnh báo annotation và `warning.json/md` khi API không khả dụng, exit0; giữ snapshot bot đầy đủ gần nhất. **Xanh cảnh báo không chứng minh bot/dữ liệu mới.** Guard repo/fixture/publish và unit test vẫn fail hard. 6. Không token cá nhân/secret mới, không sửa PMstate. GitDB vẫn chỉ root commit hai file, force duy nhất literal `bot/trang-thai`; không main/PM refs.
