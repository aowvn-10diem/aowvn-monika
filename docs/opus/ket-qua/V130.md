## Cách tái sử dụng

`scripts/ci-test-flakes.py` nhận manifest JSON đã chuẩn hóa và log job dạng `.txt` hoặc `.zip`; script chỉ ghép kết quả của cùng `head_sha` và không gọi GitHub hay in log thô. Chạy kiểm tra parser/ước lượng bằng:

```sh
python3 scripts/test-ci-test-flakes.py
```

Mỗi execution trong manifest ghi `run_id`, `attempt`, `workflow`, `head_sha`, `tests_ran`, `tests_conclusion`; thất bại cần `log_path`. Script loại lượt hỏng trước khi test chạy hoặc thiếu summary khỏi mẫu số và chỉ gắn cờ khi cùng SHA có cả fail lẫn pass, tỷ lệ lớn hơn ngưỡng.

Ví dụ hai attempt trên cùng SHA:

```json
{"executions":[
  {"run_id":123,"attempt":1,"workflow":"Build","head_sha":"<40-hex-sha>","tests_ran":true,"tests_conclusion":"failure","log_path":"logs/123-a1.zip"},
  {"run_id":123,"attempt":2,"workflow":"Build","head_sha":"<40-hex-sha>","tests_ran":true,"tests_conclusion":"success"}
]}
```
