### Bước đăng gói và điền config (PM/sếp bấm; Nova không đăng gói)
1. GitHub → Actions → "Build gói Ren'Py (đóng gói lại SDK + RAPT chính thức)" → Run workflow trên `main`: `version = 8.5.3`, `publish = true`. Cần secret `PACKS_TOKEN` (không có thì workflow đăng lên repo này — không dùng). Workflow tạo hai release `engines-renpy8-arm64-v8a-<N>` và `engines-renpy8-armeabi-v7a-<N>` (`N` = số run chung) với `renpy8-<abi>.zip` + `.sha256` trong `aowvn-monika-packs`.
2. Điền config (cần mạng, chỉ đọc link công khai):
   `python3 scripts/renpy8-config.py --version 8.5.3-r<N> --abis arm64-v8a --url 'https://github.com/aowvn-10diem/aowvn-monika-packs/releases/download/engines-renpy8-{abi}-<N>/renpy8-{abi}.zip' --fetch --write`
3. Mở PR config: `real-packs` tải đúng gói đã đăng và chạy `PackTransaction` Kotlin của app; `ConfigTest` kiểm cấu hình; `sync-config` tự đẩy lên Cloudflare sau khi gộp (đo lại bằng `curl` như V47).
4. Chưa làm bước 1 thì **không gộp** PR config: `systems[renpy].engine` bật mà gói chưa tải được sẽ khiến máy arm64 gặp màn "Không tải được" thay vì mở JoiPlay.
