1. `Failed to set current directory to <rỗng>` (run 16): `adb shell am start … --es title "CI rgss"` — dấu nháy bị shell cục bộ bóc, shell máy ảo tách "CI rgss" thành hai tham số, `game_path` mất. Sửa: bọc cả lệnh trong một chuỗi, tiêu đề không dấu cách. Thêm log `MonikaGame: rgss game_path=` để thấy giá trị.
