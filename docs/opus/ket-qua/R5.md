# R5 — lớp phủ + phím RPG Maker (V16, một phần)

Cập nhật 03/10/2026. Mã: `RgssOverlay.kt`, `RgssGameActivity.kt`, `GamePadOverlay.kt` (`VirtualPad` thành `internal`), `scripts/ci-emulator-games.sh`.

## Đã làm
- Phím ảo bố cục `RPG` (D-pad + A/B + START/SELECT) đè lên màn game; mã phím tay cầm đổi sang bàn phím RGSS (`rgssKey`: A/START → Enter, B/SELECT → X, mũi tên giữ nguyên) rồi gọi `SDLActivity.onNativeKeyDown/Up`.
- Menu Monika: Chơi tiếp · giữ Shift (chạy nhanh) · độ mờ phím (lưu `prefs.padOpacity`) · Thoát. Nút Back của máy mở/đóng menu.
- Emulator Test API 34 (run 436b07a): `OK rgss (nhúng)` + `KEY_OK` — game XP tự sinh nhận Enter qua đường SDL → mkxp-z → `Input::C`.

## Chưa kiểm
- Bấm vào phím ảo thật (CI gửi phím hệ thống, cùng đường SDL nhưng không chạm vào lớp phủ Compose); giao diện lớp phủ chưa có test Robolectric/ảnh chụp.
- "Chỉnh phím" (kéo đổi chỗ) chưa có ở RGSS.

## HOÃN theo `KE-HOACH` V16 (chờ gói rgss công khai — sếp G5/G8)
Config `modules.rgss`, `systems[rgss].engine` + `entry` (luật nhận diện game dạng thư mục: `Game.ini`/`.rgss*a`), tăng `configVersion`, `allowExternalApp: false` cho `rgss`/`kirikiri`. File config nằm trên main nên đẩy lên sẽ tác động app đang phát hành khi gói chưa có URL công khai.

## Ghi chú
Lỗi gặp: thiếu import `getValue/setValue` (Build đỏ); nhấn-nhả tức thì lọt giữa khung hình trên máy ảo chậm → CI dùng `input keyevent --longpress`.
