# Tiền duyệt (một lượt, tiết kiệm hạn mức)

Ai duyệt ai (06/10 → 10/10): **Nova** duyệt PR nhánh `sonnet/*`, `sol/*`, `haiku/*`. **Haiku** duyệt PR nhánh `nova/*`. Không bao giờ duyệt PR của chính mình. Hộp thư PM: Nova issue #90, Haiku issue #94.

## Các bước
1. Đọc rẻ: `git fetch -q origin bot/trang-thai && git show origin/bot/trang-thai:docs/trang-thai/digest.md | sed -n '/^## Open PRs/,/^## Merged/p'`. Lấy danh sách PR mở và SHA head.
2. Đọc comment mới có `[PM → <tên bạn>]` trong hộp thư của bạn (chỉ comment sau lượt trước).
3. Với mỗi PR thuộc phần của bạn:
   - PR còn draft hoặc CI trên head chưa xong thì bỏ qua lượt này.
   - Đã có comment `<Tên> tiền duyệt (commit <sha7 head>)` thì bỏ qua.
   - Còn lại thì đọc **diff thật** (`pull_request_read` với `get_diff`, chỉ phần đổi) và check run trên head, rồi viết **một** comment theo mẫu dưới.
4. Không có PR nào cần duyệt và không có thư mới thì **dừng ngay**: không comment, không báo.
5. Còn hạn mức thì làm tiếp việc được giao trong hộp thư (mỗi việc một PR, tối đa 2 PR đang chờ duyệt).

## Mẫu comment (giữ đúng dòng đầu và dòng Kết luận để bot và PM đọc được)
```
<Nova|Haiku> tiền duyệt (commit <sha7>)
1. CI trên head: <job: kết quả, run ID>
2. Phạm vi: <khớp việc nào trong KE-HOACH, có lan ra ngoài không>
3. Test: <test mới/cũ, chạy ở đâu>
4. Luật repo: <config-first + configVersion, libs.versions.toml, proguard, quyền workflow, khóa/secret>
5. Đối chiếu: <đường dẫn, hàm nêu trong PR có thật không>

Kết luận: Đạt | Cần sửa: … | Cần PM xem: …
```
Cuối comment thêm `---` + `_Generated by [Claude Code](https://claude.ai/code)_`.

## Điểm rủi ro phải nêu rõ
Quyền ghi trong workflow (`permissions: …: write`), đụng `config/monika-config.json` mà không tăng `configVersion`, thêm thư viện JNI/reflection mà không có luật `-keep`, link game/ROM/firmware trong repo, in token/khóa. Gặp một trong các điểm này thì kết luận "Cần PM xem" hoặc "Cần sửa".

## Cấm
Gộp PR, ghi "PM duyệt", phát hành, đẩy tag, sửa `docs/opus/KE-HOACH.md` hay `docs/opus/pm/**`, đọc cả log CI dài (chỉ grep dòng lỗi).
